## Website

A complete, responsive, single-page marketing website is in the `website/` folder.

**Features:**
- Fixed navigation with scroll effects
- Hero section with animated stats
- Program track comparison
- 6-module curriculum overview
- GI Bill / VET TEC benefits section
- Testimonials
- FAQ accordion
- Application form with validation
- Mobile responsive

**To run locally:** Open `website/index.html` in any browser — no build step required.

VetAI Academy bridges the gap between military service and the AI economy. Veterans bring unmatched discipline, systems thinking, and leadership. We give them the AI credentials to match.
