# VETAIML — Curriculum Outline
### AI Training for Military Veterans

---

## Program Overview

| | Full-Time Track | Part-Time Track |
|---|---|---|
| Duration | 12 weeks | 24 weeks |
| Hours/week | 40 hrs | 20 hrs |
| Format | In-person + online | Online only |
| Certification | Google / AWS / Azure AI | Same |
| Cost | $12,000 (VET TEC eligible) | $8,000 |

---

## Core Learning Outcomes

By graduation, students will be able to:
1. Explain how AI/ML systems work and where they are applied
2. Build and deploy practical AI applications using industry tools
3. Write Python scripts for data analysis and automation
4. Use generative AI tools (ChatGPT, Copilot, Claude) professionally
5. Pass at least one industry AI certification exam
6. Articulate their skills clearly in interviews and on resumes

---

## Module Breakdown

---

### Module 1 — AI Foundations (Weeks 1–2)
*"Understanding the battlefield of AI"*

**Topics:**
- What is AI, ML, and Generative AI — plain language
- History of AI and its acceleration post-2020
- AI in military/defense context (logistics, ISR, cyber, medical)
- Ethical considerations: bias, accountability, explainability
- AI career landscape and salary benchmarks

**Skills:**
- Navigate major AI platforms (OpenAI, Google, Microsoft)
- Prompt engineering fundamentals
- Use AI tools to boost personal productivity

**Project:** Write an AI-powered SOP (Standard Operating Procedure) for a veteran transition task using ChatGPT

---

### Module 2 — Python for AI (Weeks 3–4)
*"Learning the language of the machine"*

**Topics:**
- Python syntax, variables, data types, loops, functions
- Working with files, APIs, and JSON
- NumPy and Pandas for data manipulation
- Jupyter Notebooks and VS Code setup

**Skills:**
- Write Python scripts from scratch
- Read and transform datasets
- Use libraries: pandas, numpy, matplotlib

**Project:** Analyze a military occupational specialty (MOS) to civilian job crosswalk dataset using Python

---

### Module 3 — Data & AI Literacy (Weeks 5–6)
*"Intelligence drives decisions"*

**Topics:**
- What is data? Types, sources, quality
- Introduction to statistics for AI (mean, variance, probability)
- Data visualization principles
- Introduction to supervised vs unsupervised learning
- How models are trained, tested, and evaluated

**Skills:**
- Clean and visualize datasets
- Understand model evaluation metrics (accuracy, precision, recall)
- Use Google Looker Studio / Power BI for dashboards

**Project:** Build a data dashboard visualizing veteran employment outcomes by state

---

### Module 4 — Machine Learning in Practice (Weeks 7–8)
*"Building your first AI system"*

**Topics:**
- Linear and logistic regression
- Decision trees and random forests
- Classification and prediction tasks
- Introduction to scikit-learn
- Model training, validation, and deployment basics

**Skills:**
- Train and evaluate ML models
- Use scikit-learn pipelines
- Deploy a model via a simple API

**Project:** Build a classifier that predicts job fit for transitioning veterans based on MOS and skills

---

### Module 5 — Generative AI & Large Language Models (Weeks 9–10)
*"Working with AI that talks back"*

**Topics:**
- How LLMs work (transformers, embeddings, tokens)
- Prompt engineering: zero-shot, few-shot, chain-of-thought
- Building AI assistants with OpenAI API / Azure OpenAI
- Retrieval Augmented Generation (RAG)
- Fine-tuning basics and when to use it

**Skills:**
- Build a custom AI chatbot using OpenAI API
- Implement a RAG pipeline with a document knowledge base
- Write system prompts for consistent AI behavior

**Project:** Build a VA benefits Q&A chatbot that answers questions from uploaded PDF documents

---

### Module 6 — AI in the Real World (Weeks 11–12)
*"Mission-ready deployment"*

**Topics:**
- AI in cybersecurity (threat detection, anomaly analysis)
- AI in healthcare (medical imaging, triage tools)
- AI in logistics and supply chain
- Responsible AI: safety, governance, legal considerations
- Career pathways: AI engineer, ML engineer, data scientist, AI product manager

**Skills:**
- Identify AI use cases in any industry domain
- Communicate AI project value to non-technical stakeholders
- Prepare for AI certification exams

**Capstone Project:** End-to-end AI application of the student's choosing, presented to a panel of employer partners

## Tools & Platforms Used

- **Coding:** Python, VS Code, Jupyter Notebooks, GitHub
- **AI/ML:** scikit-learn, OpenAI API, Azure OpenAI, Hugging Face
- **Data:** Pandas, NumPy, Matplotlib, Power BI
- **Cloud:** Microsoft Azure, AWS, Google Cloud (free tier accounts)
- **Productivity AI:** GitHub Copilot, ChatGPT, Claude, Perplexity

---

## Student Support

- **Daily standups** — military-style accountability
- **1:1 instructor office hours** — 3x per week
- **Peer cohort study groups** — assigned battle buddy system
- **Career coaching** — resume, LinkedIn, interview prep starting Week 8
- **Alumni network** — access to VetAI alumni Slack and job board
- **Mental health resource** — partnerships with veteran mental health orgs

---

## Admissions Requirements

- DD-214 or proof of active-duty / reserve status
- Basic computer literacy (no coding experience required)
- Completed admissions interview
- Motivation letter (500 words): "How will AI training advance your mission after service?"

---

## Instructor Profile

Lead instructors must have:
- 3+ years of applied AI/ML industry experience
- Veteran status strongly preferred
- Demonstrated teaching or mentorship ability
- Up-to-date certifications in at least 2 AI platforms
